متطلبات التشغيل

سهولة في التثبيت، أداء خفيف ومستقر

البيئة المدعومة

  • ✓ نظام التشغيل: Windows 10 أو Windows 11 (64-bit)
  • ✓ الذاكرة: 8GB كحد أدنى (يفضل 16GB للنماذج المحلية الكبيرة)
  • ✓ المسرع الذكي: يدعم Ollama محلياً بنماذج Qwen2.5 و LLaMA 3
  • ✓ الصوت: ميكروفون وسماعات لدعم Whisper والـ TTS العربي

طريقة التثبيت السريعة

# 1. الاستنساخ من GitHub

git clone https://github.com/mokashreef/Aegis-AI.git

# 2. التشغيل بنقرة واحدة بدون تيرمنال

run.bat

# أو التثبيت عبر الحزمة الجاهزة مباشرة

AegisAI-Setup.exe
